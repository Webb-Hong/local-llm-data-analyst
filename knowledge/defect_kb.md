# 錫橋 (Solder Bridge)
錫橋指相鄰焊點間意外形成的多餘焊料連接，造成短路。
常見原因：鋼板開孔過大、錫膏印刷量過多、回流溫度曲線不當、刮刀壓力不足。
標準排查順序：先查錫膏印刷參數與鋼板，再查回流爐溫度曲線，最後查貼片精度。

# 假焊 (Cold Joint)
假焊指焊點未完全熔融，外觀粗糙、強度不足。
常見原因：回流溫度過低、預熱不足、焊盤氧化、元件吸濕。
標準排查順序：先查回流爐溫度曲線，再查來料儲存與烘烤記錄。

# 立碑 (Tombstoning)
立碑指片狀元件一端翹起，狀似墓碑。
常見原因：兩端焊盤受熱不均、錫膏量不對稱、貼片偏移。
標準排查順序：先查焊盤設計對稱性，再查錫膏印刷均勻度。

# 不良率異常升高的通用診斷原則
當某產線不良率短期內顯著上升（如月度翻倍），優先排查「近期發生變更的項目」：
新批次來料、設備保養或更換、製程參數調整、人員異動、環境條件變化。
重點：找出「變化點」與不良率上升時間點的關聯，而非泛泛檢查所有環節。
